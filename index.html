    08 · Partner Ops

    세부 프로그램 및 기관별 협력 추진 현황

    업데이트 방법

    1. 이 페이지의 데이터는 소스 하단 STAGE / PROGRAMS / ORGS / SG(기능성게임) / SUB(서브컬처) / CHAR(공공캐릭터) / CONTACTS(연락처) 일곱 개 스크립트 객체에 모여 있음 — 표·카드·타임라인은 전부 이 데이터에서 자동 생성됨.
    2. 추진현황 한 줄, 프로그램 추가, 무대 슬롯 변경 모두 해당 객체 값만 고치면 반영됨 — Claude에게 "○○ 협회 추진현황 업데이트해줘"라고 요청하면 됨.
    3. 상시 웹 열람이 필요한 정식 배포본은 GitHub Pages 저장소(josephwta-arch/dcf-2026-plan)로 동일 구조를 옮겨 반영 가능.
